# 문의를 사장님 구글 시트로 받기 (무료, 약 5분)

지금 홈페이지의 문의/고객센터 글은 **고객 브라우저에만** 저장되어 사장님이 볼 수 없습니다.
아래를 한 번 하면 고객이 보낸 문의가 **구글 시트에 한 줄씩** 쌓이고(선택: 메일 알림), 홈페이지 문의 버튼이 문자 앱 대신 바로 전송됩니다.

1. 구글 드라이브에서 새 **구글 시트**를 만든다. (이름 예: 홈페이지 문의)
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 코드를 지우고 `tools/inquiry-server/Code.gs` 내용을 붙여 넣는다. 메일 알림을 받으려면 맨 위 `NOTIFY_EMAIL` 에 본인 메일을 적는다.
4. **배포 → 새 배포 → 유형: 웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → 권한 허용.
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
6. `content.js` 의 `inquiryEndpoint: ""` 에 그 URL을 넣고 `python3 build.py` 를 실행한 뒤 사이트를 다시 올린다.

참고
- 주소를 비워 두면 예전처럼 **문자 앱으로 연결**됩니다.
- 이 방식은 사장님이 **받는** 용도입니다. 고객센터 게시판의 글 목록은 여전히 각자 브라우저에만 보입니다(공개 게시판이 필요하면 서버형으로 따로 만들어야 합니다).
- 코드를 고치면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.
- 자동 스팸 방지로 숨은 칸(honeypot)과 글자 수 제한이 들어 있습니다.
