# 관리자 화면 + 문의·후기 서버 (구글 시트 기반, 무료)

홈페이지 주소 뒤에 `/admin/` 을 붙이면 **사장님 전용 관리자 화면**이 나옵니다. (예: `https://내도메인.com/admin/`)

| 메뉴 | 할 수 있는 일 |
|---|---|
| 📩 문의 | 홈페이지 문의·1:1 문의 목록, 상태(신규/상담중/완료/보류), 메모, 검색, 전화·문자 바로 걸기, 엑셀(CSV) 받기, 삭제 |
| 🏠 메인 화면 | 메인 슬라이드(사진 최대 3장·제목·설명·버튼), 첫 소개 영역(하수구 막힘 케어 글·사진 칸), “왜 저희일까요” 사진 카드를 실제 사진·글로 교체 |
| 💰 가격표 | 서비스단가표 9개 페이지의 금액·표(행·칸 추가/삭제/합치기)·안내 문구 수정, 페이지별 기본값 복원 |
| 📝 기본 정보 | 홈 신뢰 띠(10년 이상·0원…), 서비스 소개 카드(사진·설명), 자주 묻는 질문, 상담 가능 시간 |
| ⭐ 후기 | 고객이 남긴 후기 승인/거절, 게시 중인 후기 수정·순서·삭제, 직접 추가 |
| 🖼 현장갤러리 | 사진 올리기(자동 축소)·제목·지역·설명·순서·삭제 → 홈페이지와 현장갤러리 페이지에 반영 |
| 📢 공지·설정 | 상단 안내 띠, 서비스 지역, 고객센터 공지사항 |
| 📺 SNS·영상 | 인스타그램·유튜브 주소, 숏츠 영상 등록(주소만 붙여 넣기 → 홈에 “숏츠 영상” 칸이 생기고 그 자리에서 재생) |
| 🎨 디자인 | 대표색·강조색 변경(프리셋·직접 선택), 홈 화면 섹션 순서·숨기기 |
| 🔑 보안 | 비밀번호 변경, 활동 기록(로그인·저장·삭제), 오래된 문의 정리, 차단된 IP 관리, 접속 IP 기록 정리 |

문의·후기는 모두 **내 구글 시트**(문의 / 후기대기 / 콘텐츠 탭)에 저장되므로 구글 시트 앱으로도 볼 수 있습니다.

## 설정 방법 (한 번만, 약 10분)

1. 구글 드라이브에서 새 **구글 시트**를 만든다. (이름 예: 홈페이지 관리)
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 코드를 지우고 `tools/inquiry-server/Code.gs` 내용을 통째로 붙여 넣는다. (맨 위 `NOTIFY_EMAIL` 에 **본인 메일을 꼭 적으세요.** 새 문의·로그인 실패 반복·비밀번호 변경이 메일로 옵니다.)
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**: 이름 `ADMIN_PASSWORD`, 값 **관리자 비밀번호**(12자 이상, 다른 곳에서 쓰지 않는 것) → 저장.
5. **배포 → 새 배포 → 유형: 웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → (처음이면) 권한 허용.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
7. `content.js` 의 `inquiryEndpoint: ""` 안에 그 URL을 넣고 `python3 build.py` 를 실행한 뒤 사이트를 다시 올린다.
8. `/admin/` 에 접속해 비밀번호로 로그인한다.
9. **(강력 추천)** 2단계 인증 켜기: Apps Script 에서 `setupTotp` 함수를 실행 → 실행 로그의 키를 인증 앱에 등록 (`보안-안내.md` 참고).

## 알아둘 점
- **보안:** 자세한 내용과 사장님이 꼭 하실 일은 `보안-안내.md` 를 읽어 주세요(구글 계정 2단계 인증 필수 권장).
- **로그인:** 비밀번호는 코드에 없고 서버(스크립트 속성)에만 있습니다. 로그인은 6시간(자리 비우면 30분) 유지되고, 틀리면 응답이 느려지며 5번 이상이면 메일로 알립니다.
- **고객센터:** 서버를 연결하면 고객센터가 **공지사항 / 이용후기 / 1:1 문의**로 바뀝니다. 1:1 문의는 사장님에게만 전달되고 다른 고객에게 보이지 않습니다. 고객이 쓴 후기는 승인 전에는 게시되지 않습니다.
- **반영 시간:** 관리자 화면에서 저장하면 방문자에게는 다음 접속 때(1회 새로고침 포함) 바뀐 내용이 보입니다.
- **코드를 고쳤을 때:** Apps Script에서 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** 해야 반영됩니다. (주소는 그대로)
- **사진:** 구글 드라이브의 `홈페이지 사진` 폴더에 저장되고 링크로 보입니다. 지우면 홈페이지에서도 사라지니 폴더를 지우지 마세요.
- **한계:** 구글 서버라 가끔 1~2초 느릴 수 있고, 하루 사용량 제한이 있어 수천 건 단위의 대형 서비스에는 맞지 않습니다. 이 규모(1인 사업장)에는 충분합니다.
- 주소를 비워 두면 서버 기능은 꺼지고, 문의는 문자 앱으로 연결됩니다.

## 시험해 보기 (구글 없이 내 컴퓨터에서)
```
cd tools/inquiry-server/test
node gas-local.js 8787 내시험비밀번호12자이상
```
`content.js` 의 `inquiryEndpoint` 를 `http://localhost:8787/exec` 로 잠시 바꾸고 사이트를 열면, Code.gs 를 그대로 흉내 낸 가짜 서버로 관리자 화면까지 전부 시험해 볼 수 있습니다. (시험 후 주소를 다시 비우세요.)

## 문의 알림 받기 (이메일 · 문자)
문의·후기가 접수되면 사장님께 바로 알려 줍니다.

### 1) 이메일 (무료, 바로 가능)
Apps Script → ⚙ 프로젝트 설정 → 스크립트 속성에 `NOTIFY_EMAIL` = 본인 메일 주소를 추가하고 새 버전으로 배포합니다(코드 맨 위 `NOTIFY_EMAIL` 에 적어도 되지만, 속성에 넣으면 주소가 공개 저장소에 남지 않습니다). 처음 한 번 “메일 보내기” 권한 허용 창이 뜹니다. 휴대폰 Gmail 앱의 알림을 켜 두면 문의 내용이 알림창에 바로 보입니다.

### 2) 문자(SMS) — 유료 문자 발송 서비스(솔라피) 사용
**내 휴대폰에 일반 문자로** 내용이 옵니다. 예) `[문의]홍길동 010-1111-2222 구로구 빌라 주방에서 바퀴벌레가…` (한글 약 45자 안에서 이름·연락처·내용 앞부분)

**비용(공식 요금 페이지에서 확인 필요, 2025년 기준 안내값):** 단문(SMS) 건당 약 18원, 장문(LMS) 약 45원, 부가세 별도. 하루 5건이면 한 달 약 2,700원 수준입니다.

**준비 순서**
1. https://solapi.com 에서 회원가입(본인·사업자 인증)
2. **발신번호 등록** — 문자를 “보내는 번호”는 미리 등록·인증된 번호만 쓸 수 있습니다. (사장님 휴대폰 번호를 휴대폰 인증으로 등록하는 방법이 가장 간단합니다. 대표번호 1661-6179 는 통신서비스 이용증명원 같은 서류가 필요할 수 있습니다. 등록 절차는 솔라피 안내를 따르세요.)
3. 문자 요금 **충전**(소액 선불)
4. 콘솔에서 **API Key / API Secret** 발급
5. Apps Script → ⚙ 프로젝트 설정 → 스크립트 속성에 아래를 추가하고 **새 버전으로 배포**(처음 한 번 “외부 서비스 연결” 권한 허용 창이 뜹니다)

| 이름 | 값 |
|---|---|
| `SMS_API_KEY` | 솔라피 API Key |
| `SMS_API_SECRET` | 솔라피 API Secret |
| `SMS_FROM` | 등록한 발신번호 (예: 01012345678) |
| `SMS_TO` | 알림 받을 내 휴대폰 (예: 01012345678, 발신번호와 같아도 됩니다) |
| `SMS_DAILY_MAX` | (선택) 하루 최대 문자 수, 기본 30 |
| `SMS_LONG` | (선택) `1` 이면 장문(LMS)으로 내용을 길게 보냄(건당 요금이 올라감) |

6. 관리자 화면 → 🔑 보안 → **알림 시험 보내기** — 휴대폰에 시험 문자가 오면 성공입니다.

**요금 폭주 방지 장치:** 스팸으로 걸러진 문의는 문자를 보내지 않고, 하루 `SMS_DAILY_MAX` 건을 넘으면 문자는 멈추지만 문의는 정상 저장됩니다(이메일은 계속 갑니다). 문자 서비스 오류나 잔액 부족도 문의 접수에는 영향이 없고, 활동 기록에 “문자 알림 실패”로 남습니다.

**주의:** 문자 알림은 **스팸 차단을 먼저 켠 뒤**(접수 표·광고 문구 필터는 기본으로 켜져 있고, Cloudflare 게이트웨이를 쓰면 더 안전) 붙이세요. 그리고 이 코드는 **솔라피 연결 시험을 이 환경에서 하지 못했습니다** (인증 방식과 호출 형식은 공식 문서대로 만들고 모의 서버로 확인). 연결할 때 위 6번 시험으로 꼭 확인하고, 거절되면 솔라피 콘솔의 발송 내역·오류 메시지를 알려 주세요.
