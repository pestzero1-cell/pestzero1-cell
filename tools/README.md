# 사진 관리 도구 (사장님 전용)

홈페이지에 쓰이는 사진을 한곳에서 보고 바꾸는 도구입니다.

## 쓰는 법
1. 이 저장소를 내 컴퓨터에 받아 `tools/photo-manager.html` 을 크롬으로 엽니다. (더블클릭)
2. 바꿀 사진 칸에서 **새 사진 선택** → 사진을 고릅니다. 크기와 용량은 자동으로 줄어듭니다.
3. **바뀐 사진 ZIP 받기** → `homepage-photos.zip` 이 내려받아집니다.
4. 압축을 풀고, 나온 `images` 폴더 안 사진을 GitHub 저장소의 `images` 폴더에 같은 이름으로 올립니다.
   (GitHub 웹: 저장소 → `images` 폴더 → Add file → Upload files)

## 보안에 대해
- 이 도구는 사진을 서버로 보내지 않고 사장님 컴퓨터 안에서만 처리합니다.
- 홈페이지 안에는 관리자 로그인 화면을 만들지 않았습니다. 서버 없는 비밀번호는 누구나 우회할 수 있어서 안전하지 않기 때문입니다.
- 실제 사이트에 반영하는 권한은 GitHub 로그인(본인 계정, 2단계 인증 권장)이 지킵니다.
- 이 파일이 사이트에 같이 올라가도 방문자는 사진을 바꿀 수 없고, 검색엔진에도 노출되지 않게 설정했습니다(noindex, robots 차단).
