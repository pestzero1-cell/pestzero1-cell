사진 관리 도구 (사장님 전용)

홈페이지에 쓰이는 사진을 한곳에서 확인하고 새 사진으로 바꿉니다.

이 도구는 사장님 컴퓨터에서만 쓰는 도구입니다. 사진은 서버로 보내지지 않고 이 컴퓨터 안에서만 처리됩니다. 홈페이지에는 비밀번호 화면을 넣지 않았습니다. 서버 없이 만든 비밀번호는 누구나 우회할 수 있어 안전하지 않기 때문입니다. 사이트에 실제로 반영하려면 GitHub에 로그인한 사장님만 파일을 올릴 수 있습니다.
  1. 바꿀 사진 칸에서 새 사진 선택을 누르고 사진을 고릅니다. (자동으로 크기를 줄이고 용량을 낮춥니다)
  2. 바뀐 사진은 초록 테두리로 표시됩니다. 여러 장을 바꿔도 됩니다.
  3. 위쪽 바뀐 사진 ZIP 받기를 누르면 images/ 폴더 구조 그대로 압축 파일이 내려받아집니다.
  4. 압축을 풀어 나온 images 폴더를 GitHub 저장소의 images 폴더에 같은 이름으로 올리면 끝입니다. (GitHub 웹에서 Add file → Upload files)
